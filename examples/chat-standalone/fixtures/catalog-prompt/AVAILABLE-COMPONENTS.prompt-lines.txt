- Stack: { direction?: "horizontal" | "vertical", gap?: "none" | "sm" | "md" | "lg" | "xl", align?: "start" | "center" | "end" | "stretch", justify?: "start" | "center" | "end" | "between" | "around", className?: string } - Flex container for layouts [accepts children]
- Card: { title?: string, description?: string, maxWidth?: "sm" | "md" | "lg" | "full", centered?: boolean, className?: string } - Container card for content sections. Use for forms/content boxes, NOT for page headers. [accepts children]
- Grid: { columns?: number, gap?: "sm" | "md" | "lg" | "xl", className?: string } - Grid layout (1-6 columns). columns is the max; it collapses in the artifact pane. [accepts children]
- Heading: { text: string, level?: "h1" | "h2" | "h3" | "h4" } - Heading text (h1-h4)
- Separator: { orientation?: "horizontal" | "vertical" } - Visual separator line
- Accordion: { items: Array<{ title: string, content: string }>, type?: "single" | "multiple" } - Collapsible sections. Items as [{title, content}]. Type 'single' (default) or 'multiple'.
- Progress: { value: number, max?: number, label?: string } - Progress bar (value 0-100)
- Skeleton: { width?: string, height?: string, rounded?: boolean } - Loading placeholder skeleton
- Badge: { text: string, variant?: "default" | "secondary" | "destructive" | "outline" } - Status badge
- Alert: { title: string, message?: string, type?: "info" | "success" | "warning" | "error" } - Alert banner
- Text: { content: string, muted?: boolean } - Text content
- Metric: { label: string, value: string, detail?: string, trend?: "up" | "down" | "neutral" } - Single metric display with label, value, and optional trend indicator
- Table: { data: Array<Record<string, unknown>>, columns: Array<{ key: string, label: string }>, emptyMessage?: string } - Data table. Use { "$state": "/path" } to bind read-only data from state.
- Link: { text: string, href: string } - External link that opens in a new tab
- BarChart: { title?: string, data: Array<Record<string, unknown>>, xKey: string, yKey: string, aggregate?: "sum" | "count" | "avg", color?: string, height?: number } - Bar chart visualization. Use { "$state": "/path" } to bind read-only data. xKey is the category field, yKey is the numeric value field.
- LineChart: { title?: string, data: Array<Record<string, unknown>>, xKey: string, yKey: string, aggregate?: "sum" | "count" | "avg", color?: string, height?: number } - Line chart visualization. Use { "$state": "/path" } to bind read-only data. xKey is the x-axis field, yKey is the numeric value field.
- Tabs: { defaultValue?: string, tabs: Array<{ value: string, label: string }> } - Tabbed content container [accepts children]
- TabContent: { value: string } - Content for a specific tab [accepts children]
- Callout: { type?: "info" | "tip" | "warning" | "important", title?: string, content: string } - Highlighted callout box for tips, warnings, notes, or key information
- Timeline: { items: Array<{ title: string, description?: string, date?: string, status?: "completed" | "current" | "upcoming" }> } - Vertical timeline showing ordered events, steps, or historical milestones
- PieChart: { title?: string, data: Array<Record<string, unknown>>, nameKey: string, valueKey: string, height?: number } - Pie/donut chart for proportional data. Use { "$state": "/path" } to bind read-only data. nameKey is the label field, valueKey is the numeric value field.
- RadioGroup: { label?: string, value?: string, options: Array<{ value: string, label: string }> } - Radio button group for single selection. Use { "$bindState": "/path" } for two-way binding. Use for multiple-choice questions, settings, or any single-select input.
- SelectInput: { label?: string, value?: string, placeholder?: string, options: Array<{ value: string, label: string }> } - Dropdown select input. Use { "$bindState": "/path" } for two-way binding. Use when there are many options and a dropdown is more compact than radio buttons.
- TextInput: { label?: string, value?: string, placeholder?: string, type?: "text" | "email" | "number" | "password" | "url" } - Text input field. Use { "$bindState": "/path" } for two-way binding. Use for free-text entry like names, emails, search, etc.
- Button: { label: string, variant?: "default" | "secondary" | "destructive" | "outline" | "ghost", size?: "default" | "sm" | "lg", disabled?: boolean } - Clickable button. Use with on.press to trigger actions like setState, pushState, etc. Can be used for quiz submissions, form actions, navigation, and more.
- Scene3D: { height?: string, background?: string, cameraPosition?: Array<number>, cameraFov?: number, autoRotate?: boolean } - 3D scene container with orbit controls. All 3D components (Sphere, Box, lights, etc.) must be children of a Scene3D. height is a CSS value like '500px'. [accepts children]
- Group3D: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, animation?: { rotate?: Array<number> } } - 3D group for positioning, rotating, and animating children together. Use to create orbits: position a planet inside a Group3D and animate the group's rotation. [accepts children]
- Box: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D box/cube mesh. args: [width, height, depth]. Supports on.press for click interaction.
- Sphere: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D sphere mesh. args: [radius, widthSegments, heightSegments]. Use higher segment counts (32+) for smooth spheres.
- Cylinder: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D cylinder mesh. args: [radiusTop, radiusBottom, height, radialSegments].
- Cone: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D cone mesh. args: [radius, height, radialSegments].
- Torus: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D torus (donut) mesh. args: [radius, tube, radialSegments, tubularSegments].
- Plane: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D flat plane mesh. args: [width, height]. Useful for ground planes or flat surfaces.
- Ring: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D flat ring mesh. args: [innerRadius, outerRadius, thetaSegments]. Great for orbit path indicators.
- AmbientLight: { color?: string, intensity?: number } - Ambient light that illuminates all objects equally. Use for base scene illumination.
- PointLight: { position?: Array<number>, color?: string, intensity?: number, distance?: number } - Point light that emits from a position in all directions. Use for suns, lamps, etc.
- DirectionalLight: { position?: Array<number>, color?: string, intensity?: number } - Directional light like sunlight. Position sets direction, not location.
- Stars: { radius?: number, depth?: number, count?: number, factor?: number, fade?: boolean, speed?: number } - Starfield background for space scenes. Renders thousands of tiny points around the scene.
- Label3D: { text: string, position?: Array<number>, rotation?: Array<number>, color?: string, fontSize?: number, anchorX?: "left" | "center" | "right", anchorY?: "top" | "middle" | "bottom" } - Text label rendered in 3D space. Always faces the camera (billboard). Use for labeling objects in a scene.
