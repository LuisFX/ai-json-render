- Scene3D: { height?: string, background?: string, cameraPosition?: Array<number>, cameraFov?: number, autoRotate?: boolean } - 3D scene container with orbit controls. All 3D components (Sphere, Box, lights, etc.) must be children of a Scene3D. height is a CSS value like '500px'. [accepts children]
- Group3D: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, animation?: { rotate?: Array<number> } } - 3D group for positioning, rotating, and animating children together. Use to create orbits: position a planet inside a Group3D and animate the group's rotation. [accepts children]
- Box: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D box/cube mesh. args: [width, height, depth]. Supports on.press for click interaction.
- Sphere: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D sphere mesh. args: [radius, widthSegments, heightSegments]. Use higher segment counts (32+) for smooth spheres.
- Cylinder: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D cylinder mesh. args: [radiusTop, radiusBottom, height, radialSegments].
- Cone: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D cone mesh. args: [radius, height, radialSegments].
- Torus: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D torus (donut) mesh. args: [radius, tube, radialSegments, tubularSegments].
- Plane: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D flat plane mesh. args: [width, height]. Useful for ground planes or flat surfaces.
- Ring: { position?: Array<number>, rotation?: Array<number>, scale?: Array<number>, color?: string, metalness?: number, roughness?: number, emissive?: string, emissiveIntensity?: number, wireframe?: boolean, opacity?: number, args?: Array<number>, animation?: { rotate?: Array<number> } } - 3D flat ring mesh. args: [innerRadius, outerRadius, thetaSegments]. Great for orbit path indicators.
- AmbientLight: { color?: string, intensity?: number } - Ambient light that illuminates all objects equally. Use for base scene illumination.
- PointLight: { position?: Array<number>, color?: string, intensity?: number, distance?: number } - Point light that emits from a position in all directions. Use for suns, lamps, etc.
- DirectionalLight: { position?: Array<number>, color?: string, intensity?: number } - Directional light like sunlight. Position sets direction, not location.
- Stars: { radius?: number, depth?: number, count?: number, factor?: number, fade?: boolean, speed?: number } - Starfield background for space scenes. Renders thousands of tiny points around the scene.
- Label3D: { text: string, position?: Array<number>, rotation?: Array<number>, color?: string, fontSize?: number, anchorX?: "left" | "center" | "right", anchorY?: "top" | "middle" | "bottom" } - Text label rendered in 3D space. Always faces the camera (billboard). Use for labeling objects in a scene.
