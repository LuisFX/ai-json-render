- RadioGroup: { label?: string, value?: string, options: Array<{ value: string, label: string }> } - Radio button group for single selection. Use { "$bindState": "/path" } for two-way binding. Use for multiple-choice questions, settings, or any single-select input.
- SelectInput: { label?: string, value?: string, placeholder?: string, options: Array<{ value: string, label: string }> } - Dropdown select input. Use { "$bindState": "/path" } for two-way binding. Use when there are many options and a dropdown is more compact than radio buttons.
- TextInput: { label?: string, value?: string, placeholder?: string, type?: "text" | "email" | "number" | "password" | "url" } - Text input field. Use { "$bindState": "/path" } for two-way binding. Use for free-text entry like names, emails, search, etc.
- Button: { label: string, variant?: "default" | "secondary" | "destructive" | "outline" | "ghost", size?: "default" | "sm" | "lg", disabled?: boolean } - Clickable button. Use with on.press to trigger actions like setState, pushState, etc. Can be used for quiz submissions, form actions, navigation, and more.
