- Metric: { label: string, value: string, detail?: string, trend?: "up" | "down" | "neutral" } - Single metric display with label, value, and optional trend indicator
- Table: { data: Array<Record<string, unknown>>, columns: Array<{ key: string, label: string }>, emptyMessage?: string } - Data table. Use { "$state": "/path" } to bind read-only data from state.
- BarChart: { title?: string, data: Array<Record<string, unknown>>, xKey: string, yKey: string, aggregate?: "sum" | "count" | "avg", color?: string, height?: number } - Bar chart visualization. Use { "$state": "/path" } to bind read-only data. xKey is the category field, yKey is the numeric value field.
- LineChart: { title?: string, data: Array<Record<string, unknown>>, xKey: string, yKey: string, aggregate?: "sum" | "count" | "avg", color?: string, height?: number } - Line chart visualization. Use { "$state": "/path" } to bind read-only data. xKey is the x-axis field, yKey is the numeric value field.
- PieChart: { title?: string, data: Array<Record<string, unknown>>, nameKey: string, valueKey: string, height?: number } - Pie/donut chart for proportional data. Use { "$state": "/path" } to bind read-only data. nameKey is the label field, valueKey is the numeric value field.
